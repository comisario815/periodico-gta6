# Leonida Daily - Periódico Digital de GTA VI

## Descripción de la temática
Este proyecto consiste en un periódico digital de noticias inspirado en el formato de diarios deportivos como MARCA, adaptado  al universo de **Grand Theft Auto VI (GTA VI)** y ambientado en el estado de Leonida y Vice City. 

La página web incluye cabecera, menú de navegación de cinco secciones, una noticia principal destacada, seis noticias secundarias organizadas mediante el sistema de rejilla de Bootstrap 5, una barra lateral con contenido popular y un pie de página detallado.
